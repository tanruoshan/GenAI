\subsection{Damage Simulation}
% P1 (span). One anchor per sentence, drawn among its fact tokens; always damaged, never dropped. One contiguous span of k
%   words around it, start = clamp(anchor - k/2). Levels: 1 word, then 10/25/50/75% of the words (half-up rounding),
%   plus a clean level 0. Spans are nested, so the same place gets worse. 850 rows with damage (750 test, 100 dev).
% P2 (noise). Each damaged word is dropped with p = 0.10 (never the anchor); otherwise 20-30% of its letters and digits
%   are changed: ~15% deleted (max 2 per word), the rest substituted from a confusion table estimated on 29 held-out
%   BLN600 excerpts (86% of substitutions; rest: capitalised table entry, look-alike map O/0, rn/m, cl/d, random char).
%   Punctuation is never touched.
% P3 (why 20-30%). Real erroneous words in the calibration excerpts have a median per-word error of 0.25
%   (q1 0.17, q3 0.40). 20-30% sits around that median; an earlier 40-60% setting sat above q3 and was dropped.

\subsection{Repair Methods}
% (a) BERT + reranking. bert-base-cased \citep{devlin2019bert}, cased because facts depend on capitals.
%   Fine-tuned on clean gold text from the 443 excerpts outside the sample (2,939 sentences; 10% of excerpts held out
%   for validation; zero overlap with test/dev, tested). Training input copies inference: span words before the target
%   are filled, the target is masked with its true piece count, later span words are one [MASK] each.
%   Inference fills slots left to right; for each slot it tries 1, 2 and 3 masks, keeps candidates, and scores
%   score = mean log-probability per piece + lambda * (1 - normalised Levenshtein distance to the garbled form).
%   This is a basic form of "context plus confusion" \citep{evershed2014correcting}. Dropped slots use the BERT score only.
%   Words with a visible hyphen or apostrophe are filled part by part; only 0.9% of slots still need more than 3 pieces.
% (b) LLM few-shot. \todo{final model id and host from teammate}. System message + instruction + 3 solved dev examples
