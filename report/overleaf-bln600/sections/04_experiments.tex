The design crosses three factors inside the same 150 test sentences: five damage levels (1 word, then 10, 25, 50
and 75\% of the sentence), three length bands (20--29, 30--44 and 45--60 words), and the repair methods of
Sec.~\ref{sec:models} (Table~\ref{tab:design}). A clean level 0 serves only the contamination probe
(Sec.~\ref{sec:metrics}). All damage levels reuse the same sentence and the same anchor word, so every comparison across levels is
paired: for one sentence we can ask directly whether repair got better, worse or stayed the same as damage grew,
rather than comparing averages over different sentences. The 20 dev sentences, disjoint from test, were used only to
pick settings (Sec.~\ref{sec:models}); five of them are the LLM's examples, so 15 are scored. Each method's setting
was frozen by a code gate before its test rows were touched, and all test scores were computed once, by one
notebook, after every method's predictions were stored.

\paragraph{Statistics.} Slots of one sentence share their context, so the sentence, not the slot, is our unit. Every
cell gets a 95\% bootstrap interval over sentences (10,000 resamples, the same resamples for all methods;
\citealp{koehn2004statistical,dror2018hitchhiker}). We test only the two comparisons that a hypothesis named before
the test run: BERT + dict.\ vs LLM (H2) and LLM vs lookup (H2b). Per level we use an exact McNemar test on anchor
recovery \citep{dietterich1998approximate} and a Wilcoxon signed-rank test on span BERTScore, with Holm's correction
\citep{holm1979simple} over the ten tests of each family. All other comparisons are descriptive.

\subsection{Metrics}
\label{sec:metrics}
% CHECKED 2026-09-29: "68 of 692" counts each fact word once (spans are nested, so the 75% span holds every fact
%   slot of the sentence): test 624 fact slots, 62 dropped; dev 68, 6 dropped. 1,830 counts the same word again at
%   every level. Visible vs dropped FRR is computed in notebook 4.
We score the repaired span, not the whole sentence, since only the span was touched. BERTScore F1
\citep{zhang2020bertscore} compares the repaired span with the gold span using \texttt{roberta-large} (layer 17),
rescaled against a baseline so that a score can go below 0; this is our primary meaning-level metric. We also report
sentence-level BERTScore, where the intact context can raise the score. \frr{} is our primary fact-level metric: the
share of gold fact tokens in the span that the repair restores exactly in their slot, punctuation ignored. Because
the share of facts among damaged words falls as the span grows (Table~\ref{tab:damage}), we also report recovery of
the anchor alone, which is the same word at every level and so gives a clean paired series for SQ1, and we split
\frr{} into fact slots with visible letters and dropped slots, which the methods must fill from context alone.

As secondary metrics we report exact-word match (the share of all span words restored exactly), span CER pooled per
level (all character edits divided by all gold characters of that level), repair gain (pooled CER before minus
after repair),\footnote{We pool CER per level rather than averaging it per row, because on a one-word span a single
wrong or over-long word can already give a row CER of 1 or more, so short spans would dominate the mean.} the LLM's
format-failure rate and its scores over valid answers only (Sec.~\ref{sec:models}), and a contamination probe. The
probe is a simplified guided completion \citep{golchin2024time,sainz2023contamination}: the LLM receives the first
half of a clean test sentence and is asked to continue it, and a continuation whose normalised Levenshtein
similarity to the true remainder (cut to the same length) is at least 0.9 counts as near-verbatim. Unlike
\citet{golchin2024time}, the prompt does not name \bln{} and there is no second condition to compare with, so a
formulaic phrase can pass the threshold by chance; we therefore read a low rate as reassuring and inspect any hit by
hand. Because of limited API resources, the probe covers 116 of the 150 test sentences.

BERTScore and \frr{} are reported side by side because they can disagree by design (SQ3): a repair that substitutes
a wrong but plausible name can still score well on meaning while scoring zero on \frr{}. To put one number on this
gap (H3) without a threshold, we take for each method and level the chance that a repair with a wrong anchor gets
at least as high a span BERTScore as a repair with the right anchor (ties count half), which is $1-\mathrm{AUC}$.
A value of 0 means BERTScore always ranks the right fact higher; 0.5 means it cannot tell right from wrong facts.
