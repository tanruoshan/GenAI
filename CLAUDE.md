## Section 0: shared code used by both tracks (build first)
### 0a. Slot view and splice (`src/blnrepair/slots.py`, model: Opus)
- Build every model input from `gold_tokens` + `ops_per_word`, never from `corrupted_text` (dossier §5 note).
- `build_slots(row)`: context words unchanged; one slot per damaged gold word, in order. Slot text = the word's `out` form in `⟨ ⟩`; a dropped word is `⟨?⟩`. Split each `out` into leading punctuation, core, trailing punctuation (punctuation was never damaged, so it is visible and fair to use).
- `splice(row, preds)`: one prediction per slot. Non-dropped slot = slot's leading punct + prediction core + slot's trailing punct. Dropped slot = prediction as returned (stripped). Context words are never rewritten.
- Level 0 rows have no slots: both tracks skip them.
- Tests (must pass before anything else): `splice(row, gold words)` returns `gold_text` token-for-token for all 1,020 rows; `splice(row, out forms)` returns `corrupted_text` for all rows; slot count equals `k`; anchor slot is never `⟨?⟩`.
- **[DECIDE] pure-punctuation gold tokens.** Some gold "words" are punctuation only (e.g. a lone `,` that was dropped). Proposal: the sanity check and later scoring compare the whole token when the gold core is empty.

### C. Reranking inference (`src/blnrepair/bert_repair.py`, model: Opus)
- Fill slots left to right. Pending slots show their visible punctuation with one `[MASK]` each. Filled slots show the chosen word.
- Current slot: for m = 1, 2, 3 masks, one forward pass; take the top-b pieces per mask position; build candidates from their combinations. Valid candidate: first piece not `##`, later pieces `##`. Keep the top N by BERT score.
- Score = mean log-probability per piece + λ × (1 minus Levenshtein distance divided by the longer length), with the similarity computed against the slot's garbled core (`rapidfuzz`). Dropped slot: BERT score only. Punctuation-only candidates are allowed only for dropped slots.
- **[DECIDE] B1 sub-slots.** BERT splits hyphens and apostrophes into their own pieces, so `police-court` or `prisoner's` needs 3 or more pieces, and names like `Neckinger-town` exceed 3. Since internal punctuation is visible in the garbled form, split such slots into parts at that punctuation and fill each part with 1 to 3 masks. Dropped slots stay whole. Decide after seeing the CHECKPOINT 1 ceiling.
- Defaults for today: λ = 1, b = 5, N = 10. The grid (λ in {0, 0.5, 1, 2, 4}, b in {3, 5}) runs later on dev with the fine-tuned model only. λ = 0 gives a "context only" reference at no extra cost.
- Batch candidates for speed. Deterministic (eval mode, no sampling).
- Today's test run: plain `bert-base-cased` (not fine-tuned) as a pipeline check, on 5 dev sentences at 1w, 25, 75. Table: gold span, slot view, prediction, sanity number, seconds per row. Label "pipeline check, not a result". Rerun with `bert_ft_v1` once it exists.
